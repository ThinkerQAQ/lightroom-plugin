自动包围曝光 HDR v2.1.2（Windows / Lightroom Classic）
=====================================================

功能
----
从当前选中的 RAW/DNG 中自动识别包围曝光序列，逐组调用 Lightroom Classic
自己的“无预览 HDR 合并”，并等待这一组的新 DNG 出现在磁盘后再处理下一组。

菜单
----
图库 > 增效工具额外功能 > [v2] 自动识别并逐组合成 HDR DNG…
图库 > 增效工具额外功能 > [v2] 测试合并当前选择一次…

使用
----
1. 先手动合并一组，设置好自动对齐、自动色调、去除重影和创建堆栈；无预览
   HDR 会沿用这套设置。
2. 在“图库”网格中选中需要扫描的一批照片。
3. 运行“[v2] 自动识别并逐组合成 HDR DNG…”，检查识别摘要后开始。
4. 处理期间保持 Lightroom 在前台，不要操作键盘和鼠标。
5. 每组最长等待 180 秒。选择、按键或 DNG 生成失败时会停止，不会跳过后
   继续提交。

识别规则
--------
- 同一文件夹、相机、焦距和图像尺寸；
- 相邻拍摄间隔不超过 2 秒；
- 曝光跨度至少 1 EV；
- 每组 2 至 9 张；
- 排除视频、虚拟副本、非 RAW/DNG 以及已有 HDR/Pano 名称的文件。

日志
----
- AutoHDR-v2.log：识别分组、文件名与 EV、选择校验、DNG 基线、等待耗时、
  成功/超时和最终汇总。
- AutoHDRInput.log：Lightroom 前台 PID、helper 身份/会话、INPUT 尺寸、
  SendInput 数量和 Win32 错误码。

两个日志都位于 LightroomAutoHDRv2.lrplugin 文件夹内。

- AutoHDR-v2-last-run.tsv：最近一次成功合成的 DNG 与每张源片的精确映射，供
  “合并原片清理助手”安全识别未建立 Lightroom 堆栈的合成组。

安全限制
--------
- v2.1.2 只生成 DNG，不删除源照片。
- Lightroom SDK 没有公开 HDR 合并接口，本插件通过 Ctrl+Shift+H 调用
  Lightroom 自己的合并功能，因此提交快捷键时 Lightroom 必须处于前台。
- 开始前请等待其他导入、导出或 HDR 任务完成，避免把其他新 DNG 误认为
  当前组的输出。
